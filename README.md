## 1. 프로젝트 개요

### 1-1. 프로젝트 소개
- **프로젝트 명** : AI·IoT 기반 고령자 낙상 예방 및 건강 모니터링 스마트 케어 침대 시스템
- **프로젝트 정의** : 침대에 부착된 압력(FSR)·초음파·자이로(MPU6050)·비접촉 레이더·진동·PIR 센서로 고령자의 자세와 생체 데이터를 실시간 수집·분석하여 낙상 위험을 3단계(정상/경고/위험)로 사전 판정하고, 위험 시 침대를 자동 제어하며 보호자 앱으로 즉시 알림을 전송하는 스마트 돌봄 시스템

### 1-2. 개발 배경 및 필요성
우리나라는 2024년 초고령사회에 진입했고, 2025년 기준 65세 이상 인구 비율이 21.21%에 달합니다. 고령·독거 인구가 늘면서 낙상 예방과 건강 모니터링에 대한 스마트 돌봄 수요도 계속 확대되고 있습니다(글로벌 스마트 헬스케어 시장은 2025년 2,524억 달러에서 2034년 7,833억 달러로 성장 전망, CAGR 13.41%). 기존 병원·요양 침대는 사용자의 상태를 자동으로 감지하는 기능이 없어 보호자의 육안 확인에 의존하고, 낙상이 발생한 뒤에야 대응이 가능하다는 한계가 있습니다. 본 프로젝트는 AI 기반 위험 예측을 통해 낙상이 발생하기 전 위험 상황을 분석하고 자동으로 대응하는 것을 목표로 합니다.

### 1-3. 프로젝트 특장점
- FSR·초음파·MPU6050·비접촉 레이더·진동·PIR 센서를 융합한 낙상 위험·침대 이탈 실시간 감지
- RandomForest 기반 위험확률 산출로 낙상 "발생 후 대응"이 아닌 "발생 전 예측·대응"
- 위험 감지 시 서보모터로 침대 기울기 자동 제어(사용자가 직접 조절하던 기존 방식과 차별화)
- 장시간 동일 자세를 감지해 자동으로 체위 변경 신호를 보내는 욕창 예방 기능
- 비접촉 레이더로 별도 의료기기 없이 심박·호흡을 실시간 모니터링
- 비상 정지 버튼, 동시 동작 방지 등 이중 안전 설계 적용

### 1-4. 주요 기능
- **낙상 위험 실시간 판정** : 13개 특징 벡터(FSR 4채널 통계값, 가속도 크기·변동성, 거리·PIR·진동·심박·호흡)를 3초마다 계산해 RandomForest 모델로 정상/경고/위험 3단계 분류
- **자동 제어·경보** : 위험 시 서보모터로 자세 보정, 부저·LED·OLED로 즉시 경고
- **건강 모니터링** : 레이더(MR60BHA1) 기반 비접촉 심박·호흡 측정, 무호흡·심박이상 감지
- **욕창 예방** : 4시간 이상 동일 자세 유지 시 자동 체위 변경 신호 전송
- **보호자 앱 연동** : 실시간 상태 확인, 위험 알림, 기록 조회, 수면 리포트 제공
- **수면 분석** : 뒤척임·수면 패턴 분석 리포트 생성

### 1-5. 기대 효과 및 활용 분야
- **기대 효과** : 고령자 낙상 사고의 조기 감지·예방, 보호자 돌봄 부담 경감, 응급 대응 시간 단축, 욕창 등 2차 합병증 예방
- **활용 분야** : 요양시설·병원 병상, 독거노인 돌봄 서비스, 가정 내 고령자 케어, 재활 환자 모니터링

## 3. 시스템 구성도

### 서비스 구성도
`사용자(고령자) → ① 사용자 상태 감지(FSR/MPU6050/초음파/레이더/진동/PIR) → ② ESP32 제어부(수집·전처리·MQTT) → ③ 서버(데이터·이벤트·사용자 관리) → ④ AI 분석 엔진(RandomForest 확률 기반 위험단계 판정) → ⑤ 출력·구동 장치(서보/부저·LED·OLED/비상호출) 및 ⑥ 보호자 앱(실시간 모니터링·위험 알림·수면 리포트)`

### 서비스 흐름도
1. 사용자가 스마트 케어 침대를 이용하는 동안 시스템이 작동
2. 센서가 압력·진동·자세·거리·생체신호·움직임을 실시간 수집
3. ESP32가 데이터를 수집·전처리 후 Wi-Fi/MQTT로 서버에 전송
4. AI 분석 엔진이 RandomForest 확률 기반으로 정상(0.3 미만)/경고(0.3~0.6)/위험(0.6 이상) 판정
5. 위험 감지 시 침대 자동 제어(서보) + 부저·LED·OLED 경고 출력
6. 위험 상황 발생 시 보호자 앱으로 실시간 알림 전송
7. 모든 이벤트·측정 데이터를 서버에 저장해 수면 리포트·이력 조회에 활용

### 기능 처리도
| 센서·입력(H/W) | 판정·제어 | 출력·구동 |
|---|---|---|
| 압력 FSR / 거리 초음파·PIR / 자세 IMU / 생체 레이더(호흡·심박) / 진동 | 다중 판정 로직 → 위험 조건 충족 시 위험 3단계화(정상 시 유지) | 서보모터 작동 / 부저 경보음 / LED 초록·빨강 / OLED 텍스트 |

> [실사용 다이어그램(서비스 구성도, 서비스 흐름도, ERD, 하드웨어 배선도) 이미지는 `제작설계서`에서 캡처하여 이 섹션에 추가해주세요.]

## 5. 핵심 소스코드

**소스코드 설명** : `realtime_fall_scorer.py` — 3초마다 최근 센서 데이터로 13개 특징 벡터(FSR 4채널 통계, 가속도 크기·변동성, 거리·PIR·진동·심박·호흡)를 계산하고, 사전 학습된 RandomForest 모델(`fall_risk_rf_model_v2`, 검증 정확도 91.4%)로 낙상 위험확률을 산출해 정상/경고/위험 3단계로 실시간 판정하는 로직입니다. 위험 단계에서는 MQTT로 액추에이터(서보모터)에 자세 보정 신호를 전송합니다.

```python
FEATURES = [
    "fsr_mean", "fsr_std", "fsr_max", "fsr_min", "fsr_range",
    "accel_mag", "fsr_mean_roll_std", "accel_mag_roll_std",
    "DIST", "PIR", "SW420", "HEART", "BREATH",
]

RISK_PROB_THRESHOLD = 0.6   # 이 확률 이상이면 "위험" 단계
RISK_WARN_THRESHOLD = 0.3   # 이 확률 이상이면 "경고" 단계

X = pd.DataFrame([feat])[FEATURES]
proba = clf.predict_proba(X)[0]
classes = list(clf.classes_)
risk_prob = proba[classes.index("fall_risk")]

# 정상 / 경고 / 위험 3단계 판정
if risk_prob >= RISK_PROB_THRESHOLD:
    level = "위험"
elif risk_prob >= RISK_WARN_THRESHOLD:
    level = "경고"
else:
    level = "정상"

if level == "위험":
    upsert_fall_event(BED_ID, risk_prob, feat, lean, severity="critical", level=level)
    publish_actuator_command(BED_ID, LEAN_TO_COMMAND[lean])   # 서보 보정 신호 전송
elif level == "경고":
    upsert_fall_event(BED_ID, risk_prob, feat, lean, severity="warning", level=level)
    publish_actuator_command(BED_ID, "0")   # 경고 단계는 기록만, 과잉반응 방지
else:
    resolve_fall_event(BED_ID)
    publish_actuator_command(BED_ID, "0")
```
