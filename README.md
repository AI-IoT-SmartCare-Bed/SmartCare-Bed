# Smart Care Bed - Fall Detection System

AI·IoT 기반 고령자 낙상 예방 스마트 케어 침대 시스템의 낙상 감지 모듈

## 프로젝트 정보

- **프로젝트명**: AI·IoT 기반 고령자 낙상 예방 및 건강 모니터링 스마트 케어 침대 시스템
- **수행 기간**: 2026년 4월 ~ 10월
- **진행사**: 2026 ICT 한이음 드림업
- **팀 구성**: 김응표 멘토님 전민주 박다솔 이아인

## 본 저장소의 범위

본 저장소는 **낙상 감지 시스템**을 구현하며, 전체 스마트 케어 침대 시스템의 기본 모듈입니다.

- 압력센서(FSR) + 초음파센서(HC-SR04) 이중감지
- AND 로직을 통한 오인식 방지
- 실시간 경보 (LED, 부저, 서보)
- OLED 디스플레이 상태 표시

## 시스템 개요

전체 스마트 케어 침대 시스템의 구조:

```
┌─────────────────────────────────────────────────────┐
│        하드웨어 센서층                              │
│ FSR/로드셀 + IMU + 레이더 + PIR + 초음파          │
└──────────────────┬──────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────┐
│     임베디드 제어층 (ESP32)                        │
│ 센서 수집 → 액추에이터 제어 → MQTT 통신          │
└──────────────────┬──────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────┐
│    AI · 데이터층 (Python)                          │
│ 전처리 → 낙상 위험 분류 → 수면 분석               │
└──────────────────┬──────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────┐
│   보호자 앱층 (Flutter + MQTT)                     │
│ 실시간 대시보드 → 푸시 알림 → 수동 제어           │
└─────────────────────────────────────────────────────┘
```

### 본 저장소 위치
- **영역**: 임베디드 제어층 (낙상 감지 모듈)
- **기능**: FSR + 초음파 센서 읽기 → AND 판정 → 경보

## 주요 기능

- **이중감지 AND 로직**: 압력센서 ≥ 600 AND 거리 ≤ 25cm 동시 만족 시에만 위험 판정
- **오인식 방지**: 단일 센서만 반응하면 정상 상태로 유지
- **실시간 경보**:
  - LED: 초록(정상) ↔ 빨강(위험)
  - 부저: 3회 울림
  - 서보모터: 침대판 복귀 (3초)
- **상태 표시**: OLED 디스플레이에 "NORMAL MODE" 또는 "FALL DETECTED" 표시

## 기술 스택

- **마이크로컨트롤러**: ESP32-S3
- **프로그래밍 언어**: C++ (Arduino)
- **개발 환경**: Arduino IDE
- **라이브러리**:
  - Wire (I2C)
  - Adafruit_GFX (그래픽)
  - Adafruit_SSD1306 (OLED)
  - ESP32Servo (서보 제어)

## 하드웨어 구성

### 센서 입력
| 부품 | GPIO | 규격 | 설명 |
|------|------|------|------|
| FSR 압력센서 | GPIO4 | ADC | 침대 가장자리 압박 감지 |
| HC-SR04 TRIG | GPIO13 | 디지털 | 초음파 송출 |
| HC-SR04 ECHO | GPIO14 | 디지털 | 초음파 수신 |

### 출력 장치
| 부품 | GPIO | 규격 | 설명 |
|------|------|------|------|
| 서보모터 (MG996R) | GPIO5 | PWM | 침대판 복귀 |
| 부저 | GPIO6 | 디지털 | 경고음 |
| LED 초록 | GPIO7 | 디지털 | 정상 상태 표시 |
| LED 빨강 | GPIO15 | 디지털 | 위험 상태 표시 |
| OLED SDA | GPIO11 | I2C | 화면 데이터 |
| OLED SCL | GPIO12 | I2C | 화면 클록 |

## 작동 원리

### AND 로직
```
조건 1: 압력센서값 ≥ 600
조건 2: 초음파 거리 ≤ 25cm

결과:
(조건1 AND 조건2) = 위험 판정 → 경보 발동
기타 조합 = 정상 상태 유지
```

### 상태 변화
```
정상 → 위험 전환:
  1. LED: 초록 → 빨강으로 변경
  2. 부저: 3회 울림
  3. OLED: "FALL DETECTED" 표시
  4. 서보: 침대판 들어올림 (3초)

위험 → 정상 복귀:
  1. LED: 빨강 → 초록으로 변경
  2. OLED: "NORMAL MODE" 표시
```

## 임계값 조정

환경에 따라 임계값 수정이 필요할 수 있습니다.

### 측정 방법
```
1. 시리얼 모니터 열기 (Tools → Serial Monitor, 115200 baud)
2. 정상 상태에서 FSR값과 거리값 기록
3. 낙상 시뮬레이션 상황에서 FSR값과 거리값 기록
4. 구간별 범위 파악
```

### 임계값 설정 원칙
```
FSR_THRESHOLD = 정상값의 최대값 + 마진(50~100)
DISTANCE_THRESHOLD = 침대 정상 거리 + 마진(10~15cm)

예시:
- 정상 FSR 범위: 100~500 → 임계값 600
- 정상 거리 범위: 5~10cm → 임계값 25cm
```

### 코드 수정
```cpp
const int FSR_THRESHOLD = 600;        // 필요시 수정
const float DISTANCE_THRESHOLD = 25.0; // 필요시 수정
```
